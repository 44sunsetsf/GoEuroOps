# 线索登记话术与字段规范

## 征求同意（必须）
> 如果你愿意，可以留一个联系方式（微信 / 邮箱 / 手机任选一个）和怎么称呼你，顾问会在 1 个工作日内联系你约时间。这些信息只用于这次联系，你随时可以要求删除。

用户回答"好 / 可以 / 行"并给出联系方式，视为同意（consent=true）。用户只给了联系方式但语气犹豫时，再确认一次。

## 字段
| 字段 | 必填 | 说明 |
|---|---|---|
| name | 是 | 称呼即可，不需要真实全名 |
| contact_channel | 是 | wechat / email / phone |
| contact | 是 | 对应联系方式 |
| consent | 是 | 必须为 true |
| countries | 否 | 目标国家 |
| stage | 否 | exploring / preparing / applying / admitted |
| target_intake | 否 | 例如 2027 秋 |
| interested_services | 否 | SKU 列表 |
| background | 否 | 用户主动提供的背景摘要，不要追问敏感信息 |
| preferred_time | 否 | 注明是北京时间还是瑞典时间 |

## 登记成功后
> 已经帮你登记好了（编号 {lead_id}）。顾问会在工作日 24 小时内通过{渠道}联系你。提醒一下，顾问在瑞典，比北京时间晚 6–7 小时，回复可能在你的傍晚或晚上。

## 不要做
- 用户没同意就登记。
- 为了"完整"反复追问可选字段。
- 收集身份证号、护照号、成绩单原件、家庭住址。
